기능 정의서

시스템 구성, 기능 목록과 우선순위, 뺀 기능

1. 개요

주제AI 협동로봇 기반 공장&창고 안전관리 시스템
MechDog 4대가 대피 통로를 순찰하며 막힘 · 바닥 물건을 찾아 사람이 치우게 하고, 화재 때는 막힌 길을 피해 비상구로 안내한다.
로봇MechDog(소형 4족 보행 로봇) 4대 · 2대 순찰 + 2대 충전 · 교대 · 이상이 생기면 대기 로봇까지 출동
사용자관리자: 관제 확인 · 현장 조치 · 체크로 해제 / 현장 작업자: 화재 때 화살표 따라 대피

2. 시스템 구성

한 방향 사람
번호보내는 쪽 → 받는 쪽내용
①MechDog → 서버지나간 마커 · 상태(움직임 · 멈춘 이유 · 배터리) · 온도 · 사진 — 로봇은 좌표를 모르고 서버가 추정
②서버 → 대시보드로봇 추정 위치 · "의심" 이벤트 · 지도의 통로 차단 · 바닥 물건 주의
③대시보드 → 관리자알림
④관리자 → 서버확인 · 조치 후 체크로 해제
⑤서버 → MechDog순찰 시작 · 인계 / 이동(교대 · 도크 복귀 · 교차 확인 · 갈림길 안내) / 출발 · 합류 허가 / 양보(정지 · 재개 · 후진) / LED 표시(화살표 · ✕)
장비하는 일상태
바닥 카메라라인 · 마커 · 바닥 물건(초음파에 안 잡히는 낮은 물체)장착 시험함 (자세를 높이면 색 구분 가능)
머리 카메라앞쪽 시야 · 사람 검출(YOLO) · 화재마운트 3D 프린트 예정
초음파장애물 거리 (걸으며 측정, 안 되면 마커에서 멈춰 측정)MechDog 기본
온도 센서화재모델 · 4개/2개 정할 것

3. 기능 목록

ID기능한 줄 설명센서 · 장비우선담당

F-02위치 특정바닥 마커로 지금 구역을 안다 (종류는 ArUco / 색 띠 실험 후 결정)바닥 카메라Must
F-03통로 막힘 감지통로 위 장애물을 찾아 위치 보고초음파 + 비전Must
F-04관제 화면지도에 위치 · 이상 표시, 사람이 체크해 해제대시보드Must
F-05지나가는 사람 거르기움직이는 사람은 제외, 서 있는 사람은 장애물 (연속 사진 + YOLO)머리 카메라 + 서버
F-06화재 감지표면 온도 45℃ 초과 시 멈춰 계속 측정 → F-12로 확정 (시연은 캔들)온도 센서 + 카메라
F-07대피 안내화재 확정 시 4대가 갈림길에 서서 LED로 비상구 방향(화살표) · 진입 금지(✕) 표시서버 + LED
F-08릴레이 교대배터리 20% 미만 → 대기 로봇이 이어 순찰, 지친 로봇은 도크(충전 자리)로서버
F-09재점검 · 복구치운 뒤 재통과로 통로 복구 · 순찰 자동 복귀초음파 + 비전
F-10바닥 물건 감지낮은 물건 → "밟힘 주의" · 순찰 계속 · 사람이 치우고 체크바닥 카메라
F-11쓰러진 사람 감지오래 누워 있거나 안 움직이면 알림카메라
F-12교차 확인두 번째 로봇이 가서 다시 재고, 둘 다 50℃ 초과면 화재 확정 (오탐 방지)온도 센서 · 서버
F-13다중 로봇 교통 관리로봇끼리 마주치지 않게 구간별 한 방향 · 출동 길 예약 · 양보 · 막히면 한쪽 후진서버

우선순위: Must 없으면 시연이 안 됨 · Should 협업 · 차별점 · Could 완성도

6. 확인할 것

  • 마커 종류: ArUco · 색 띠를 걸으며 읽어 보고 결정
  • 초음파: 걸으며 재지는지 (안 되면 마커 간격 25 / 50cm 중 결정) · 코너에서 랙 오인식
  • 누운 사람: 방향별로 서 있는 사람과 구분
  • 바닥 카메라: 높이 · 각도 · 마커 여러 개 동시 인식 · 후진 때 꺾기 마커 재인식
  • 머리 카메라: 화면 위아래 나눠 쓰기
