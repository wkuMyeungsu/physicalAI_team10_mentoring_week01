## 구조 및 반영 방법

- 팀 프로젝트 원본 폴더는 `07_corp-project/docs/` (`YYYY-MM-DD/` 날짜 폴더 + `index.html`), 내부 회의록·녹음 아카이브는 `07_corp-project/archive/`에 보관합니다.
- `07_corp-project/docs/`에서 문서를 수정·추가한 뒤 아래 명령으로 이 저장소 `main`에 반영합니다.

```bash
python scripts/publish_log.py -m "1주차 문서 정리 및 반영"
```
